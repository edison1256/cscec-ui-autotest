# 中建云生产上线后必测回归走查全景套件 (Release Smoke & Walkthrough Suite)

本文档定义了中建云每次迭代需求在**生产环境上线当天**必须执行的自动化回归走查全景套件。该套件融合了 **PC 端生产冒烟 Checklist** 与 **移动端定制首页走查 Checklist**，严格遵循**只读、快速、高覆盖、零写入风险**原则。

控制台各路径的真实交互深度、入口类型和缺口以 `docs/prod-console-interaction-matrix.md` 为准；用例数量不能替代交互层级覆盖率。

---

## 🎯 1. 核心设计原则与执行口径

1. **零写入安全隔离 (Zero-Write Guarantee)**：
   - 生产环境默认锁定 `-m "smoke and readonly"`，**严格拦截并排除 182 条非生产默认用例**（包括写操作、显式执行、候选稳定化和专项用例）。
   - 走查用例涉及的搜索输入仅做即时填充与清空，不发起产生落库数据的动作。
2. **生产双域名口径 (Domain Split)**：
   - **工作台/服务中心/门户栏目/移动端工作台**默认走 `https://cloud.cscec.com/`。
   - **控制台管理页**默认走 `https://irp.cscec.com/udpweb/portal/index.html#/portal/...`。
   - 文档中心上线切换期优先尝试 `cloud` 工作台深链，若被 CAS 或旧路由拦截，自动回退到 `irp` 兼容深链。
3. **多端全链路覆盖**：
   - **PC 端**：覆盖登录认证、门户 6 大只读路由、控制台管理页、全部菜单视图、10 大菜单组健康检查、控制台可复现常用模块入口、文档中心、资源基线。
   - **移动端**：覆盖 `cloud` 域名下的定制首页容器、搜索栏、金刚区网格、轮播公告、待办卡片、推荐服务列表（41 项）、底部 TabBar 切换、个人中心及主流机型多视口兼容性。
4. **执行时间与指标**：
   - 全套件共 **106 条自动化走查用例**，数量随已稳定生产探查持续增长；
   - 执行方式：无人值守自动化运行，当前生产实测耗时约 **10~15 分钟**。
