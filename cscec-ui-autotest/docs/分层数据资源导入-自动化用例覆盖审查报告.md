## 五、遗留项与后续建议（含优先级 + 代码骨架）

### 高优先（建议近期补）
1. **M04 重复跳过/覆盖**（对应大纲 M04「表里/库里重复」）：需先预置一个可重复的实体+字段组合，再构造两行相同「域+系统+L1-L3+表英文名+字段英文名」数据。代码骨架：
```python
def test_m04_duplicate_attribute_conflict_modes(self, layered_import_page, tmp_path):
    run_id = import_run_id("m04_dup")
    # 两行相同字段英文名（需保证表英文名指向已存在实体）
    rows = [
        m04_valid_attribute_row(headers, f"auto_field_{run_id}"),
        m04_valid_attribute_row(headers, f"auto_field_{run_id}"),
    ]
    import_file = create_workbook_from_headers(tmp_path, f"{run_id}.xlsx", headers, rows)
    layered_import_page.upload_file(import_file)
    layered_import_page.click_validate_table()
    layered_import_page.select_conflict_mode("跳过")   # 或 覆盖
    layered_import_page.click_confirm_import()
    layered_import_page.should_show_import_finished()
```
2. **M04 属性子列表逐字段核验**（字段类型/安全分级在属性列表中的精确展示）：需先定位「数据资源列表 → 进入实体 → 属性列表」的导航路径，再断言列值与列头。当前 `test_m04_09` 已覆盖「导入成功 + 按字段英文名检索」，精确列核验待补定位。

### 中优先

4. **M04 定位错误独立用例**：`m04_locator_mismatch_row` / `m04_missing_locator_row` 已备构造器，补独立 test（当前仅 `test_m04_04` 覆盖「实体不存在」）。
