## 3. UAT 探查证据

### 3.1 数据资源管理页

入口路径稳定：门户首页 -> 控制台新页签 -> 数据资源管理。

UAT 页面实际可见按钮：

- `手动添加`
- `导入数据实体清单(M03)`
- `导入数据属性清单(M04)`

当前页面未看到 `M02` 或 `导入数据分层清单` 按钮。

### 3.2 M02 入口

结论：2026-08-12 复核后，入口/模板合同可纳入自动化实施。

2026-08-11 探查结果：

- 数据资源管理页没有 M02 导入按钮。
- 控制台菜单搜索 `分层`、`数据分层`、`M02` 后，可见 `数据分层设置`。
- 打开 `数据分层设置` 后，页面 URL 为 `/sub/resource/systemManage/layerSet`，页面只展示 `数据分层设置`，未发现导入按钮、模板下载或 M02 文案。

2026-08-12 复核结果：

- 打开 `数据分层设置` 后，页面 URL 仍为 `/sub/resource/systemManage/layerSet`。
- 页面可见 `导入数据分层清单` 按钮。
- 弹窗标题为 `导入数据分层清单`，存在上传文件 input。
- 弹窗可下载 `M02数据分层清单.xlsx`。
- 模板表头为：`一级应用域名称`、`L1`、`L1定义`、`L2`、`L2定义`、`L3`、`L3定义`。

处理方式：

- `UI-CAND-0001`、`UI-CAND-0068` 先按入口、上传控件和模板下载合同自动化。
- `UI-CAND-0014` 到 `UI-CAND-0028` 中涉及真实导入、重复处理、覆盖、删除的数据类用例，仍需单独设计前端证据和测试数据回收策略。

### 3.3 M03 入口、模板和错误证据

结论：适合进入下一批 UAT 自动化试点。

已确认：

- `导入数据实体清单(M03)` 弹窗可打开。
- 弹窗存在 `上传文件` 控件。
- `下载模板` 可下载 `M03数据实体清单.xlsx`。
- 模板可解析 13 个表头：
  `一级应用域编号`、`一级应用域名称`、`应用系统编码`、`应用系统名称`、`L1`、`L2`、`L3`、`表中文名称`、`表英文名称`、`表描述`、`存储周期`、`数据责任部门`、`系统项目组`。
- 使用模板表头构造一行不存在数据后，前端稳定显示：
  `校验失败，错误行号：2`、`错误 1 行`、`第 2 行：一级应用域不存在`。
- 错误证据呈现在弹窗文本中，不是 `.ant-table-row` 表格行；自动化断言应读取弹窗文本和行号文本。

已有试点补充：

- `UI-CAND-0006` 的 M03 列名不符用例已通过 UAT，系统提示 `导入Excel列名与模板不符！`，且不会新增数据资源。

### 3.4 M04 入口、模板和错误证据

结论：适合进入下一批 UAT 自动化试点，但规则类用例需先做代表性自动化，不宜一次性铺满。

已确认：

- `导入数据属性清单(M04)` 弹窗可打开。
- 弹窗存在 `上传文件` 控件。
- `下载模板` 可下载 `M04数据属性清单.xlsx`。
- 模板可解析 28 个表头。
- 上传列名错误文件后，前端稳定显示 `列名与模板不符/模板不符` 类提示。
- 使用模板表头构造一行不存在/非法数据后，前端稳定显示：
  `校验失败`、`错误行号：2`、`错误 1 行`、`第 2 行：一级应用域不存在`，并追加是否主键、是否可空、是否外键、是否本系统产生的数据、数据安全类别、是否国资监管等字段值不正确提示。
- 错误证据同样呈现在弹窗文本中，不是 `.ant-table-row` 表格行。

## 5. 下一步建议

建议下一步只实施一个小批次：

1. 扩展 `DataResourcePage` 的通用导入弹窗能力，支持 M03/M04 打开、模板下载、按模板表头生成错误文件、读取弹窗错误文本。
2. 新增 M03/M04 导入弹窗契约用例，覆盖 `UI-CAND-0002`、`UI-CAND-0003`、`UI-CAND-0069`。
3. 新增 M03 单行业务错误代表用例，覆盖 `UI-CAND-0030`。
4. 新增 M04 单行业务错误代表用例，先覆盖 `UI-CAND-0045` 或 `UI-CAND-0048` 的代表性错误。
5. UAT 通过后再更新 `incoming` 和 `registry`，不要在未跑通前把候选状态改成 automated。

暂不建议本轮处理：

- M02 真实导入、重复处理、覆盖和推送类用例。
- 重复跳过/覆盖。
- 正向成功导入。
- 删除、上下架、移动顺序等状态变更类回归。
