## 动态校验

- 查询数量、页数、账户数均来自本轮数据，不固化历史 38/58/5/37。
- 页面行与响应行按资源、模式、应用（控制台另含租户）比较，允许行顺序不同；父表同名模式具有不同 ID 时，由实际展开请求的 `instanceIds` 唯一绑定当前父行，不能把同名直接当业务重复或猜测数组顺序。缺失、串行及真正重复的租户/资源 ID/模式 ID 仍判失败。
- 父表订阅数量与子表真实行数、当前响应聚合账户数比较；父行原始 `instanceIds` 与各聚合账户 `instanceIds` 的并集对照，再校验资源 ID、服务模式、应用及各账户当前累计用量。多次购买的原始实例数可以大于聚合账户数，不能拿代表账户 `id` 或订单数替代。
- 查询对照本轮可见资源编码，组合反例来自另一个真实资源；空结果用本轮随机不存在编码。
- 重置核对本轮请求筛选对象是否恢复默认以及 UI/当前响应一致，不要求两次总数相等，避免期间正常新增数据导致误报。
- 计量样本从本轮分页选择非零调用账户，额度对照账户 UI、当前响应及接口合计；日明细读取所有分页再比较合计，不固化 2459。
- 接口用量与当前账户关联的汇总响应比较；日明细请求的账户/接口 ID 必须来自该汇总，日期、次数、额度逐条与当前响应核对。分页流程独立选择本轮较大正向样本，必须实际有第二页；没有跨页样本不判分页通过。
- 日期筛选使用当前成功订单日期；导出区间从当前日明细最小/最大日期推导。固定次数仅用于连续操作的测试强度，不是业务数据期望值。
- 订单查询对照当前账户订单 ID 集合与真实响应，再打开完整表单核对订单、资源、模式、状态和本人创建人；不凭“没有某个人姓名”证明隔离。
- 实际下载 CSV 与当前全部分页日明细逐行对照，两次导出的日期/次数/额度均一致才通过，不用字节哈希代替数值对账。原人工 CSV 已验证列名“已调用额度”，对应页面“已调用额”；仅接受这两个明确名称并记录实际列名。哈希、文件名和重复 BOM 独立记为观察，不借重复导出稳定性用例声称已修复。

缺少正向样本标为 `DATA_REQUIRED`；业务响应非成功、字段不符、数量/累计不一致保留失败，不转成缺数据或历史通过。

## 隔离与证据

UAT/生产在登录前跳过，并有 PRE URL 和请求域名护栏。PRE 控制台实际使用 `iamuat.cscec.com` 的共享 SSO，只有认证域名放行，业务 `/irp-api/` 仍限 `cloud-pre.cscec.com`、`irp-pre.cscec.com`；这不运行 UAT 业务测试。共享埋点被抑制，已观察的图标 CDN 仅允许静态 GET。

只用本轮浏览器的内存登录态，不读取或覆盖个人浏览器或 `auth_states/`。工作台、控制台和不同租户使用独立上下文；流程间不继承展开、筛选、弹窗状态。浏览器会在会话结束关闭。默认无界面运行，角色画像使用 1920x1440，不能据此宣称 1080 高度或移动端兼容通过。

不同租户分别建立 SSO 会话；认证缓存按域和租户角色隔离，切换后只在门户、进入业务模块之前刷新基线，不缓存打开过的业务页签。缺少角色或认证失败不变成业务通过。

普通租户按已执行人工记录的本人订阅路径加载，不把管理租户的“管理后台”入口套到普通租户，也不据此宣称普通租户菜单导航通过。该路径可用画像中的 `personal_subscription_path` 覆盖，业务地址仍受 PRE 护栏约束。

截图与观察数据保存在唯一 `reports/metering260901/blackbox-时间-随机标识/`。结果记录包括 setup/call/teardown，每轮归档在结果路径旁的 `runs/<run_id>/results.json`；主结果文件只代表本轮。多个流程关联同一编号时按最严重结果汇总，登录/适配失败不标为业务断言通过。

运行开始及每个阶段均写入当前结果，`exitstatus=-1` 表示尚未正常结束；中途退出不能读取上轮结果当作本轮结果。全量扫描及多账户订单核验有独立的有限超时，日志输出当前域、页码和本轮总数，便于排查慢页。

使用 `tools/generate_metering_outline_260901.py --source <原大纲> --output <独立大纲> --results <本轮结果JSON>` 可生成独立自动化大纲，原文件保持不变。
